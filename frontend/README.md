# Staffify Frontend Client

**Tech Stack:** React.js, Vite, Tailwind CSS, Lucide React, Axios

---

## Project Overview

**Staffify** is an enterprise-grade Workforce Management & Human Resource Management System (HRMS) frontend.
It provides complete operational visibility across attendance, leaves, payroll, recruitment pipelines, employee directory, and AI copilots.

---

## Key Features

- **Enterprise Brand Identity**: Custom Staffify geometric squircle emblem and design system.
- **AI Copilot & Assistant**: Real-time natural language query assistant for workforce analytics.
- **Attendance & Biometrics**: Real-time check-in/out, geofencing, IP lock, and swipe logs.
- **Leave Management**: Leave requests, approvals, balance tracking, and sandwich leave rules.
- **Payroll & Statutory Deductions**: Salary slips, tax computations, EPF, ESIC, and bonus payouts.
- **Recruitment ATS**: Candidate pipeline, interview schedules, and hiring workflows.
- **Dark / Light Mode**: Unified theme switching with complete persistent state.

# Staffify

A full-stack staff and gig management portal.

## Structure
- `frontend/` - React, Vite, Tailwind CSS client
- `backend/` - Node.js, Express, MongoDB API

## Setup & Running

### 1. Backend
```bash
cd backend
npm install
node index.js
```
Server runs on `http://localhost:5000`.

### 2. Frontend
```bash
cd frontend
npm install
npm run dev
```
Client runs on `http://localhost:5173`.
